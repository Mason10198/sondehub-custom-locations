# Mozilla reviewer source instructions

This archive contains the complete source required to reproduce the unsigned SondeHub Custom Locations XPI submitted to Mozilla Add-ons.

## Environment

- Node.js 20 or newer
- npm with lockfile support
- Python 3
- Linux, macOS, or Windows

The project has no runtime npm dependencies. `package-lock.json` contains only project metadata.

The release checks run on Ubuntu through GitHub Actions with Node.js 20 and Node.js 24. The source archive has also been verified locally on Linux x86-64 with Node.js 22 and Python 3.13. It does not use native npm modules or platform-specific build tools.

## Build

From the archive root:

```sh
npm ci --ignore-scripts
npm run verify:vendor
npm run generate:icons
npm test
npm run lint
npm run package
npm run verify:package
```

The resulting unsigned package is:

```text
dist/sondehub-custom-locations-1.6.4.xpi
```

## Generated and vendored files

- `src/shared/icons.js` is generated by `scripts/generate-icon-catalog.js` from every SVG in `third_party/heroicons/optimized/16/solid/`.
- The vendored Heroicons revision, license, tree hash, and upstream links are recorded in `THIRD_PARTY_NOTICES.md`.
- `npm run verify:vendor` verifies the complete vendored tree and license.
- `npm run generate:icons` regenerates the runtime catalog deterministically.
- `scripts/package.py` packages an exact 12-file runtime allowlist with fixed ZIP metadata.
- `npm run verify:package` builds twice, compares hashes, checks ZIP integrity, rejects duplicate or unexpected paths, and compares packaged bytes with source bytes.

No minifier, transpiler, bundler, native compiler, or remote build service is used.

## Source archive verification

The repository can also reproduce and verify this source archive:

```sh
npm run package:source
npm run verify:source
```

`verify:source` extracts the archive into a clean temporary directory, verifies vendored assets, regenerates the icon catalog, runs the tests, builds the XPI, and confirms that the rebuilt XPI is byte-identical to the release XPI.

See `AMO_LISTING.md` for reviewer notes and `PRIVACY.md` for the public privacy policy.
