# Code of conduct

## Our standard

Contributors and maintainers are expected to keep project spaces welcoming, constructive, and focused on improving the extension. Treat people with respect, accept good-faith feedback, and disagree about technical decisions without attacking individuals.

Unacceptable behavior includes harassment, discriminatory language, threats, sexualized attention, deliberate disruption, publishing another person's private information, or pressuring someone to disclose personal location data, credentials, or browser-profile information.

## Project privacy

Use synthetic locations in issues, pull requests, tests, and screenshots. Remove personal coordinates, account details, credentials, AMO secrets, and browser-profile data before sharing diagnostics.

## Enforcement

Report conduct concerns privately through the maintainer's GitHub profile. Do not open a public issue containing sensitive personal information. Maintainers may edit or remove contributions and may temporarily or permanently restrict participation when necessary to protect the community.

## Scope

This code applies in this repository and in other public spaces when someone is representing the project.
