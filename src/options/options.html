Backup and restore

Desktop Firefox synchronizes saved locations through your Firefox account. Firefox for Android does not synchronize extension storage, so use CSV export and import when moving data to or from mobile.

Import CSV

Required columns: name,icon,lat,long. Optional color columns: icon_color,background_color. Colors use six-digit hex values such as #000000.
