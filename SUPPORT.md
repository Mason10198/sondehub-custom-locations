# Support

## Questions and usage help

Before opening an issue:

1. Read the installation, usage, CSV, troubleshooting, privacy, and limitations sections in [`README.md`](README.md).
2. Confirm the problem occurs on a supported SondeHub URL and a supported Firefox version.
3. Temporarily load the current `main` branch and check whether the problem is already fixed.
4. Search existing issues for the same symptom.

For a reproducible bug or compatibility regression, open a GitHub issue and include:

- Extension version or commit.
- Firefox edition, version, and operating system.
- Exact supported SondeHub URL.
- Steps to reproduce and expected/actual behavior.
- Whether the problem occurs after reloading the temporary add-on and map tab.
- Sanitized console errors when relevant.

Do not attach real personal coordinates, exported browser profiles, credentials, AMO secrets, or other private data. Use synthetic locations when reproducing a problem.

## Feature requests

Describe the practical use case and any privacy, permission, network, or Android impact. The project intentionally avoids a backend, analytics, telemetry, remote assets, and broad host permissions.

## Security issues

Do not open a public issue for a suspected vulnerability. Follow [`SECURITY.md`](SECURITY.md).
